# Πριν γίνουμε τρεις — v0.14 Cinematic Reader

Αυτή η έκδοση περνά την εγκεκριμένη οπτική κατεύθυνση μέσα στην πραγματική εμπειρία ανάγνωσης.

## Τι να ελέγξεις
1. Cover Gate → «Μπες στην ιστορία».
2. Άνοιγμα Κεφαλαίου 1.
3. Μετάβαση στις πρώτες επιλογές.
4. Άνοιγμα Κεφαλαίου 2: πρέπει να εμφανίζεται το πραγματικό φωτογραφικό hero.
5. Επιλογή → branch → Συνέχισε.
6. iPhone portrait και desktop.
