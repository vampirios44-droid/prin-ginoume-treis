# Πριν γίνουμε τρεις — v0.16 Motion & Memory Audit

## Τι να ελέγξεις
1. Κάνε μια νέα διαδρομή από την αρχή.
2. Στις μεταγενέστερες επιλογές πρέπει να εμφανίζονται διακριτικά callbacks με τίτλο **«Κάτι που έμεινε»**.
3. Τα A/B/C παραμένουν αόρατα.
4. Οι choice cards πρέπει να μπαίνουν με ήπιο stagger.
5. Μετά την επιλογή, το branch πρέπει να εμφανίζεται απαλά και να γίνεται scroll προς αυτό.
6. Τα chapter hero visuals πρέπει να έχουν πολύ διακριτική κινηματογραφική κίνηση, όχι εφέ τύπου game.
